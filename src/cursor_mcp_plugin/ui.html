About Talk To Figma Plugin

This plugin allows Cursor AI to communicate with Figma, enabling AI-assisted design operations. Github

Version: 1.1.0

How to Use

  1. Make sure the MCP server is running in Cursor
  2. Connect to the local relay or enter a remote ws:///wss:// address
  3. Once connected, you can interact with Figma through Cursor

Anonymous usage analytics (plugin opens, command names, success/error) are sent to Google Analytics to help improve the plugin. No file content or personal data is collected.
